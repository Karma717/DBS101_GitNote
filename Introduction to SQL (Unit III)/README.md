# Learning SQL: Communicating with Databases

## Introduction

SQL (Structured Query Language) is the standard language used to interact with relational databases. This unit introduced the basic operations used to manage and retrieve data.

## Key Concepts Learned

### SQL Data Definition

SQL allows users to create, modify, and delete database objects such as tables.

### Basic Queries

The SELECT statement retrieves information from tables.

### Additional Operations

Filtering, sorting, and grouping data improve query results.

### Set Operations

UNION, INTERSECT, and EXCEPT combine results from multiple queries.

### Null Values

NULL represents missing or unknown information.

### Aggregate Functions

Functions such as COUNT, SUM, AVG, MIN, and MAX perform calculations on groups of data.

### Nested Subqueries

Queries can be embedded inside other queries to solve complex problems.

### Database Modification

INSERT, UPDATE, and DELETE statements modify existing data.

## Reflection

Learning SQL felt like learning a new language. I discovered how powerful simple commands can be when working with large datasets.

## Conclusion

SQL is a fundamental skill for anyone working with databases and serves as the primary tool for data manipulation and retrieval.
