# Designing Better Relational Databases

## Introduction

This unit focused on creating efficient relational database structures through normalization and dependency analysis.

## Key Concepts Learned

* Good database designs minimize redundancy.
* Functional Dependencies describe relationships between attributes.
* Normal Forms improve database quality.
* Decomposition divides tables while preserving information.
* Multivalued Dependencies handle more complex relationships.
* Temporal Data models time-related information.

## Reflection

Normalization initially seemed complicated, but I understood that it prevents duplication and maintains consistency.

## Conclusion

Relational database design principles help create efficient, maintainable, and scalable databases.
