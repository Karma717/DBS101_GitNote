# Unit I: Introduction to Database Systems

## Introduction

Data has become one of the most valuable resources in the digital age. Every application we use, whether it is a social media platform, an online shopping website, or a banking system, depends on databases to store and manage information efficiently. In this unit, I learned the fundamental concepts of database systems, their purpose, architecture, and the different people involved in managing them.

## Understanding the View of Data

A database system allows users to interact with data without worrying about how it is physically stored. This concept is known as data abstraction. Database systems typically provide three levels of abstraction:

* Physical Level – Describes how data is stored on storage devices.
* Logical Level – Describes what data is stored and the relationships among the data.
* View Level – Presents only the relevant information to specific users.

This layered approach simplifies database usage and improves security.

## Purpose of Database Systems

Before database systems were developed, organizations relied on file-processing systems. These systems often suffered from problems such as:

* Data redundancy
* Data inconsistency
* Difficulty in accessing data
* Security issues
* Lack of data integrity

Database systems were introduced to overcome these challenges by providing centralized and efficient data management.

## History of Database Systems

Database technology has evolved significantly over time:

1. File-Based Systems – Data stored in separate files.
2. Hierarchical Databases – Data organized in a tree structure.
3. Network Databases – Data connected through complex relationships.
4. Relational Databases – Data organized in tables and accessed using SQL.
5. Modern Databases – Includes distributed, cloud, and NoSQL databases.

Today, relational database systems remain the most widely used because of their simplicity and flexibility.

## Database-System Applications

Database systems are used in many sectors, including:

### Banking

Managing customer accounts, transactions, and loans.

### Education

Maintaining student records, course information, and examination results.

### Healthcare

Storing patient records, medical histories, and appointment schedules.

### E-Commerce

Managing products, customers, orders, and payments.

### Telecommunications

Tracking calls, billing information, and customer subscriptions.

These examples demonstrate how databases support critical business operations.

## Database Languages

Database systems use specialized languages to interact with data.

### Data Definition Language (DDL)

Used to define database structures.

Examples:

* CREATE
* ALTER
* DROP

### Data Manipulation Language (DML)

Used to retrieve and modify data.

Examples:

* SELECT
* INSERT
* UPDATE
* DELETE

The most commonly used database language today is SQL (Structured Query Language).

## Database Design

Database design is the process of organizing data efficiently. A well-designed database:

* Minimizes redundancy
* Improves consistency
* Enhances performance
* Supports future expansion

Database designers often use Entity-Relationship (ER) models to represent data and relationships before implementation.

## Database Engine

A database engine is the core component responsible for:

* Storing data
* Retrieving data
* Processing queries
* Managing transactions
* Ensuring security and consistency

Without the database engine, users would not be able to interact effectively with stored information.

## Database and Application Architecture

Database systems can be organized using different architectures.

### Two-Tier Architecture

The application communicates directly with the database.

### Three-Tier Architecture

The application interacts through an intermediate application server before reaching the database.

Three-tier architecture is commonly used in modern web applications because it improves security and scalability.

## Database Users and Administrators

Several groups of people interact with database systems:

### End Users

Use applications to access data.

### Application Programmers

Develop software that communicates with databases.

### Database Designers

Design database structures and relationships.

### Database Administrators (DBAs)

Responsible for security, backup, performance tuning, and maintenance.

The DBA plays a crucial role in ensuring the database operates efficiently and securely.
